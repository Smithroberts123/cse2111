# CSE 2111 Project Database

A student-built study hub for CSE 2111 (Modeling and Problem Solving with Spreadsheets and Databases) at Ohio State: lab walkthroughs, practice quizzes and exam help for Excel and Access.

It's a plain static site with no build step. Open `index.html` locally, or serve the repo root with GitHub Pages (Settings → Pages → Branch: `main`, folder `/ (root)`).

This is an unofficial resource and doesn't replace official lab directions or SimNet files.
