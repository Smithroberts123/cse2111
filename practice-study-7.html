    Quiz 7 study guide: Reference Functions

    The core Chapter 7 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    VLOOKUP and HLOOKUP

    FunctionSyntaxSearchesReturns from
    VLOOKUPVLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])Down the first columnColumn number you give (1 = first column of the table)
    HLOOKUPHLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])Across the first rowRow number you give (1 = first row of the table)

    The only real difference is orientation: vertical tables use VLOOKUP, horizontal tables use HLOOKUP.

    Exact vs. approximate match

    range_lookupFindsTable must be sorted?Use for
    TRUE or left outExact match, or else the largest value that is less than or equal to the lookup valueYes, ascendingBrackets: grades, tax rates, shipping weights, discounts
    FALSEExact match onlyNoIDs, names, codes
    Remember: leaving range_lookup out means TRUE, not FALSE.

    Worked example: shipping costs

    F
    Weight (lb)    		G
    Cost
    20$5
    32$8
    45$12
    510$20
    620$35
    FormulaResultWhy
    =VLOOKUP(7, $F$2:$G$6, 2, TRUE)$12Largest weight ≤ 7 is 5
    =VLOOKUP(25, $F$2:$G$6, 2, TRUE)$35Above every value, so it uses the last row
    =VLOOKUP(-1, $F$2:$G$6, 2, TRUE)#N/ASmaller than the smallest value
    =VLOOKUP(7, $F$2:$G$6, 2, FALSE)#N/ANo exact 7
    =VLOOKUP(7, $F$2:$G$6, 3, TRUE)#REF!The table has only 2 columns

    Setting up the table correctly

    Leave the labels out. If row headings like “Qty” and “Discount” sit in column A, start the table_array at the data: use $B$1:$F$2, not $A$1:$F$2.

    ABCDEF
    1Qty1102550100
    2Discount0%5%8%12%15%

    =HLOOKUP(H5, $B$1:$F$2, 2, TRUE) returns 8% for a quantity of 30.

    Make the table absolute. When you copy a lookup down a column, the lookup value (like A2) should move, but the table shouldn’t: =VLOOKUP(A2, $F$2:$G$6, 2, TRUE).

    Why lookups instead of nested IFs

    A long nested IF is cumbersome to write and hard to maintain. A lookup table puts the breakpoints in cells where anyone can read and update them, and the formula stays short. (Nested IFs can return text and numbers, so that’s not the reason.)
