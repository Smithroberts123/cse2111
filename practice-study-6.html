    Quiz 6 study guide: IF Functions

    The core Chapter 6 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    How IF works

    =IF(logical_test, value_if_true, value_if_false)

    ArgumentWhat it isExamples
    logical_testAnything that reduces to TRUE or FALSEB2>=60, AND(D2, B2>40), or just D2 if it holds TRUE/FALSE
    value_if_trueWhat to return if the test is TRUE"Pass", 10, C2*1.1, TRUE
    value_if_falseWhat to return if the test is FALSE"Fail", 0, B2*C2, ""

    Unlike AND, OR, and NOT, which only return TRUE or FALSE, IF can return text, numbers, calculations, or Boolean values.

    Quotes, TRUE, and blanks

    FormulaWhat happens
    =IF(A1>0, "approved", "denied")Correct: text results in quotes
    =IF(A1>0, approved, denied)Excel looks for ranges named approved/denied, and shows #NAME? if they don’t exist
    =IF(D2="TRUE", …)Compares to the text “TRUE,” so it’s FALSE even when D2 holds TRUE
    =IF(D2, …) or =IF(D2=TRUE, …)Correct ways to test a TRUE/FALSE cell
    =IF(5>9, "Yes")value_if_false left out, so it returns FALSE
    =IF(B2>100, "", B2*2)"" makes the cell look blank

    Nested IFs

    To choose between more than two results, put another IF in the value_if_false spot. The course notes allow up to 64 levels.

    =IF(C4<50, "Low", IF(C4<80, "Medium", "High"))

    Excel stops at the first TRUE test. That makes order critical:

    Order trap: =IF(G2>=60, "D", IF(G2>=70, "C", …)) gives a 95 a “D,” because 95>=60 is TRUE first. With >=, test the highest cutoff first. With <, test the lowest first.

    IF with AND, OR, NOT

    Use a Boolean function as the logical_test when several conditions matter: =IF(AND(D2, B2>40), "Review", "") or =IF(OR(1>5, 3=3), 10, A1*2).

    IF inside a calculation

    IF can be one piece of a bigger formula. Base pay plus a commission only when the target is hit:

    =B4+IF(B2>=10000, B5, 0) gives the same result as =IF(B2>=10000, B4+B5, B4).

    A nested IF can pick a rate that’s then multiplied: =IF(C4<1000, 0, IF(C4<2000, 0.02, 0.05))*C$1.

    Worked example: overtime pay

    A
    Name    		B
    Hours    		C
    Rate    		F
    Inputs
    1OT multiplier1.5
    2Kai45$20OT threshold40

    =IF(B2>$F$2, $F$2*C2+(B2-$F$2)*C2*$F$1, B2*C2)

    Kai worked more than 40 hours, so: 40 × 20 = 800 regular, plus 5 × 20 × 1.5 = 150 overtime, for 950. The inputs use $F$2 and $F$1 so the formula can be copied down the list.
