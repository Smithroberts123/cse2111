    Quiz 2 study guide: Basic Functions & Cell Addressing

    The core Chapter 2 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    How functions work

    A function is a pre-built formula with an algorithm already programmed into Excel. You write its name and give it arguments in parentheses: =ROUND(B2, 2). For list-style functions like SUM, argument order doesn’t matter. For functions like ROUND, each position means something specific.

    The basic functions, and what they skip

    Example range A2:A6 holds 12, (blank), pending, 8, 0.

    FunctionWhat it doesResult for A2:A6
    SUMAdds the numbers20
    AVERAGESum ÷ how many numbers6.67 (20 ÷ 3)
    MIN / MAXSmallest / largest number0 / 12
    COUNTCounts cells with numbers3
    COUNTACounts non-empty cells (numbers and text)4
    COUNTBLANKCounts empty cells1
    Key rule: SUM, AVERAGE, MIN, MAX, and COUNT ignore blanks and text labels in a range. A 0 is a real number and counts, so it pulls an average down. If a range has no numbers at all, MIN and MAX return 0 and AVERAGE returns #DIV/0!.

    Functions are safer than operators here: if A2 contains text, =A1+A2 gives #VALUE!, but =SUM(A1:A2) just skips the text.

    Error values

    You seeIt meansTypical cause
    #DIV/0!Dividing by zeroThe bottom of a division is 0 or blank, like =G2/(H2-H3) when H2 = H3

    ROUND

    =ROUND(number, num_digits) changes the actual value, unlike formatting, which only changes the display. Halfway values round away from zero.

    num_digitsRounds toExampleResult
    2Hundredths=ROUND(3.14159, 2)3.14
    0Whole number=ROUND(76.5, 0)77
    −1Tens=ROUND(845, -1)850
    −2Hundreds=ROUND(1234.567, -2)1200

    Relative, absolute, and mixed references

    When you copy a formula, relative parts shift by however far it moved. A $ locks whatever comes right after it.

    TypeLooks likeWhen copied
    RelativeA1Column and row both shift
    Absolute$A$1Never changes
    Mixed (row locked)A$1Column shifts, row stays
    Mixed (column locked)$A1Row shifts, column stays

    Worked example: =A$1*$B2 in C3 copied to E6 moves 2 columns right and 3 rows down. A$1 becomes C$1 (column moves, row locked) and $B2 becomes $B5 (column locked, row moves), giving =C$1*$B5.

    Pressing F4 on a reference cycles through $A$1, A$1, $A1, then back to A1.

    Named ranges

    A name like TaxRate always points to the same cells, so it acts like an absolute reference when copied. Names can’t contain spaces, can’t start with a number, and can’t look like a cell address such as B12.
