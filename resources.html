    Lab resources

    Every lab in one place: which files to grab from SimNet, what to submit, and the notes that save you time.

    Always download your start files from your own SimNet session.

    SimNet adds a hidden signature to each start file that ties it to you. A file from anywhere else, including a classmate or this site, gets blocked when you submit and can show up in an integrity report. Reference copies of directions and data files are posted below so you can look things up anytime, but do the lab in, and submit, the files you download yourself. Start files (.accdb, .xlsx) are never posted here.

    Submit to SimNet

    • Research Papers Master.accdb

    Key notes

    • Part 1: type the first 5 Client records by hand, then import from Excel.
    • Import order: Client, PaymentMethod, Payments, Charges. Expect 16, 5, 11, 23 records.
    • Part 3: build tables and relationships before importing. Order: Customer, Instructor, Class, Class Enrollment.
    Reference copiesRead and check only. Never submit these.
