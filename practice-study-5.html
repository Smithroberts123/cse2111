    Quiz 5 study guide: Boolean Functions

    The core Chapter 5 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    Relational operators

    A relational expression compares two values and returns TRUE or FALSE. These operators are evaluated last, after all the math on each side.

    OperatorMeaningExampleResult
    =Equal to=6*2=3*4TRUE
    <>Not equal to=10-4*2<>2FALSE
    > / <Greater / less than=12>10TRUE
    >= / <=Or equal to=7>=7TRUE

    Comparing text and logical values

    FormulaResultWhy
    ="Ohio"="OHIO"TRUEText comparisons ignore case
    ="apple"<"banana"TRUEText compares alphabetically
    ="TRUE"=TRUEFALSEText “TRUE” is not the logical value TRUE
    ="10"=10FALSEText “10” is not the number 10

    AND, OR, NOT

    FunctionReturns TRUE whenExampleResult
    AND(…)Every argument is TRUE=AND(TRUE, 3>1, 5<>5)FALSE
    OR(…)At least one argument is TRUE=OR(FALSE, 2+2=5, "a"="A")TRUE
    NOT(x)Its one argument is FALSE=NOT(4*3>10)FALSE

    AND and OR arguments can be any mix of cell references, comparisons, and ranges, as long as each piece reduces to TRUE or FALSE: =OR(A2, B2>50, C2:C4). NOT takes exactly one argument, so to negate several conditions, wrap them: =NOT(OR(B3, C3)).

    Turning words into formulas

    WordingUse
