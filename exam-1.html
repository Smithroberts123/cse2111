    Exam 1 help: Excel through IF

    What’s on the exam, how to work each question, a one-page syntax sheet, the mistakes that cost the most points, and an original exam-style practice set. Your lecture slides and the Practice Exam on Carmen are still the official source.

    Exam format

    • Taken in CarmenMultiple choice and fill-in questions. The Practice Exam on Carmen shows what the real one looks like.
    • One workbook, many questionsYou get an image of an Excel workbook plus a problem description, then answer questions about formulas for specific cells.
    • Function syntax sheet providedYou don’t need to memorize argument order, but you do need to know which function fits and where the $ signs go.

    What’s covered

    Every function covered so far except reference and financial functions (those are on Exam 2). The main focus is everything up through the IF function, especially embedded IFs and IFs that use Boolean functions and relational operators with several conditions. Use cell references whenever you can.

    How to approach each question

    1. Skim the problem firstGet the big picture of the workbook. Come back for details only when a question needs them.
    2. Do the easy ones firstDon’t lose points on a question you know because you ran out of time on a hard one.
    3. Say it in English, then translateBreak the question into small pieces (“lost means out before the cutoff AND not returned”), then write each piece in Excel syntax.

    Then check your $ signs. Ask which way the formula gets copied:

    Copied…Only worry aboutExample for a fixed cell
    Down a column$ before the row numberUnits!B$3
    Across a row$ before the column letter$B3
    Both waysThink about each part separatelyAVERAGEIF($C$3:$C$12, $A3, D$3:D$12)

    Syntax sheet

    Criteria in COUNTIF(S), SUMIF(S), AVERAGEIF(S)

    Criterion is…How to write itExample
    A numberType it=COUNTIF(C1:C10,5)
    TextIn quotes=COUNTIF(E1:E10,"USA")
    A cellType the reference=COUNTIF(G1:G10,A2)
    A typed-in comparisonWhole thing in quotes=COUNTIF(I1:I10,">=5")
    A comparison to a cellOperator in quotes, then & and the cell=COUNTIF(K1:K10,">="&A2)
    Wildcard* inside quotes=COUNTIF(M1:M10,"USA*")

    TRUE, FALSE, AND, OR, and NOT never go in quotes. In a regular formula (not a criterion), comparisons have no quotes: =A2>=B2.

    Conditional functions: argument order

    FunctionOrder
    COUNTIF / SUMIF / AVERAGEIF(range to check, criterion, [range to add or average])
    COUNTIFS(range1, criterion1, range2, criterion2, …)
    SUMIFS / AVERAGEIFS(range to add or average first, then range1, criterion1, range2, criterion2, …)

    The -IFS versions require every condition (AND). For “this or that” in the same column, add two single-condition functions: =SUMIF(C:C,"DRA",H:H)+SUMIF(C:C,"COM",H:H).

    Other functions

    FunctionKey pointExample
    ROUND2 = hundredths, 1 = tenths (ten cents), 0 = whole, −1 = tens, −2 = hundreds. ROUND goes on the outside.=ROUND(AVERAGE(A2:A9),1)
    COUNT / COUNTACOUNT counts numbers. COUNTA counts anything not empty.=COUNTA(A2:A9)
    LARGE / SMALL(range, k): the k-th largest or smallest=LARGE(H$3:H$19,2)
    RANK.EQ(number, list, order). 0 or blank = highest is 1. 1 = lowest is 1.=RANK.EQ(D3,D$3:D$19,0)
    SUMPRODUCTMultiplies matching items, then adds. Ranges must be the same size.=SUMPRODUCT(B2:B5,C2:C5)

    Boolean patterns

    In wordsPattern
    All / both / everyAND(…)
    Any / either / at least oneOR(…)
    None / neitherNOT(OR(…)) or AND(NOT(a),NOT(b),…)
    Only this oneAND(this, NOT(OR(all the others)))
    Between 50 and 80AND(E2>=50,E2<=80) (never 50<=E2<=80)

    IF and embedded IF

    =IF(logical test, value if true, value if false). The logical test must come out TRUE or FALSE: a relational comparison, a Boolean function, or a cell that already holds TRUE/FALSE (just write IF(H4,…)).

    For tiers, go in order. With >= start at the highest cutoff. With < start at the lowest:

    =IF(B7>=B$5,C$5,IF(B7>=B$4,C$4,IF(B7>=B$3,C$3,C$2)))

    Common mistakes

    MistakeFix
    Using IF just to show TRUE or FALSE: =IF(A2>5,TRUE,FALSE)Write the test itself: =A2>5
    Writing IF(H4=TRUE,…)IF(H4,…)
    Comparing a whole range: =B2:B9>50Compare cells one at a time, or count with COUNTIF(B2:B9,">50")
    Cell reference inside the quotes: ">=A2"">="&A2
    COUNTIFS for “or” in one columnTwo COUNTIFs added together
    Missing $ on a fixed cell (a rate or cutoff on another sheet)Lock the row when copying down, the column when copying across
    Typing a value that’s in a cell, like *20Point to the cell: *Units!B$5
    Embedded IF tested in the wrong orderBiggest cutoff first with >=
    NOT(AND(…)) for “none”NOT(OR(…)). NOT(AND) means “not all.”
    Sheet name with a space, not quoted='Sales Data'!B4
