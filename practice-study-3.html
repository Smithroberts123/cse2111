    Quiz 3 study guide: Spreadsheet Design

    The core Chapter 3 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    What makes a good spreadsheet design

    A spreadsheet that gives the right answer can still need redesigning. Good designs are:

    GoalWhat it meansSign it’s missing
    CorrectFormulas produce the right resultsTotals don’t match hand checks
    Easy to read and useClear labels, units, and an obvious input areaOthers can’t tell what to change
    Easy to changeValues can be updated in one spotConstants are typed inside formulas
    Easy to extendNew variables or cases fit without rewritingAdding a region means redoing formulas

    Plan first. Sketching the layout before building avoids time-consuming changes later.

    Inputs, outputs, and keeping data in one place

    Put assumptions (tax rates, prices, growth rates) in a labeled input area, and have formulas in the output area reference those cells. Don’t type constants like 0.0725 into formulas.

    Data should appear only once. If a value is needed elsewhere, reference it (=Inputs!B2) instead of retyping it. Two typed copies will eventually disagree.

    What-if analysis and Goal Seek

    Input/output (what-if) analysis: change the input values and watch the outputs recalculate. You change values, never the formula cells.

    Goal Seek (Data, What-If Analysis, Goal Seek) works backward: you name the result you want and it finds the input that produces it.

    Dialog boxWhat goes thereExample
    Set cellThe formula whose result you want to hitB10 (profit)
    To valueThe target number50000
    By changing cellOne input cell holding a value, not a formulaB3 (price)

    Limitations: Goal Seek adjusts only one cell, and that cell must contain a constant, not a formula. The Set cell has to depend on it.

    Multiple worksheets and 3-D references

    When each case (a month, a store, a scenario) gets its own sheet with an identical layout, a summary sheet can combine them with a 3-D reference: the same cell across a span of sheets.

    GoalFormula
    Total D8 on Jan through Mar=SUM(Jan:Mar!D8)
    Sheet names with spaces=SUM('Week 1:Week 4'!C3)
    Average a range across sheets=AVERAGE(Jan:Mar!B2:B10)

    The span includes every sheet positioned between the first and last tab. Drag a sheet into that span and it’s included; drag it out and it isn’t.

    Freeze Panes

    Freeze Panes (View tab) keeps headers on screen while you scroll. It freezes everything above and to the left of the selected cell, so you can freeze rows and columns at the same time. Select C3 to freeze rows 1–2 and columns A–B. It only affects the view, not the data.

    Paste Special: Values and Transpose

    OptionWhat it does
    ValuesPastes the results as plain numbers or text, with no formulas
    TransposeFlips orientation: rows become columns. A 3 × 5 block becomes 5 × 3.

    Checking both pastes a flipped, formula-free snapshot.

    Reference reminders

    A formula like =B4*$F$2 mixes a relative reference (B4) with an absolute one ($F$2), which is the classic pattern for applying one input cell to a whole column. For sheets with spaces in their names, use quotes: ='Tax Rates'!D9.
