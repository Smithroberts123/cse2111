    Quiz 4 study guide: Conditional Functions, LARGE, SMALL & RANK

    The core Chapter 4 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    Sample data used below

    A
    Region    		B
    Rep    		C
    Sales
    2EastKim400
    3WestLee250
    4EastAna150
    5NorthKim300
    6WestAna500
    7EastLee250
    8NorthAna100

    One condition: COUNTIF, SUMIF, AVERAGEIF

    SyntaxExampleResult
    COUNTIF(range, criteria)=COUNTIF(A2:A8, "East")3
    SUMIF(range, criteria, [sum_range])=SUMIF(A2:A8, "East", C2:C8)800
    AVERAGEIF(range, criteria, [average_range])=AVERAGEIF(B2:B8, "Ana", C2:C8)250

    The last argument of SUMIF and AVERAGEIF is optional. Leave it out when you’re adding or averaging the same cells you’re testing: =SUMIF(C2:C8, ">300") gives 900. If nothing matches, AVERAGEIF returns #DIV/0!.

    Several conditions: COUNTIFS, SUMIFS, AVERAGEIFS

    SyntaxExampleResult
    COUNTIFS(range1, crit1, range2, crit2, …)=COUNTIFS(A2:A8, "East", C2:C8, ">200")2
    SUMIFS(sum_range, range1, crit1, …)=SUMIFS(C2:C8, A2:A8, "West", B2:B8, "Ana")500
    AVERAGEIFS(avg_range, range1, crit1, …)=AVERAGEIFS(C2:C8, A2:A8, "East")266.67
    Watch the argument order. SUMIF and AVERAGEIF put the sum/average range last (optional). SUMIFS and AVERAGEIFS put it first (required). COUNTIFS has no separate count range, only criteria pairs.

    Multiple criteria are AND logic: a row counts only if every condition is true. All ranges must be the same size, or you get #VALUE!.

    Writing criteria

    You wantWriteNotes
    Equals a number100No quotes needed
    Equals text"Blue"Not case-sensitive
    Greater than 250">250"Operator and number together in quotes
    Not equal to East"<>East"
    Greater than the value in E1">"&E1Operator in quotes, cell outside, joined with &

    The classic mistake is ">E1", which compares against the text “E1” instead of the cell’s value. These rules are identical for all six IF and IFS functions.

    LARGE and SMALL

    LARGE(array, k) returns the k-th largest value and SMALL(array, k) the k-th smallest. The range comes first, then k. With the sample sales, =LARGE(C2:C8, 2) is 400 and =SMALL(C2:C8, 3) is 250. LARGE with k = 1 equals MAX, and SMALL with k = 1 equals MIN. The array can be a block like A1:C10.

    RANK.EQ

    RANK.EQ(number, ref, [order]) tells you a value’s position in a list.

    orderRank 1 isExampleResult
    0 or left outThe largest=RANK.EQ(C5, C2:C8) (300)3
    1The smallest=RANK.EQ(C4, C2:C8, 1) (150)2

    Ties share a rank and the next rank is skipped: two values tied for 4th means the next is 6th. When copying a RANK.EQ formula down a list, make the list absolute: =RANK.EQ(C2, $C$2:$C$8).

    Copying in two directions

    For a summary grid with criteria down a column and across a row, you usually need mixed references:

    =COUNTIFS($A$2:$A$8, $E3, $B$2:$B$8, F$2)

    The data ranges are fully absolute. $E3 locks the column so it always reads row labels from E, and F$2 locks the row so it always reads column headers from row 2.
