    Quiz 1 study guide: Spreadsheet Basics

    The core Chapter 1 ideas in one place. Read this, then try the practice set. Your course notes are still the official source.

    What spreadsheets are for

    Businesses use spreadsheets to organize data, calculate with it, and present the results: budgets, balance sheets, forecasts, payroll, inventory and project costs, and data analysis. Their big strength is what-if analysis: change one input and every formula that depends on it recalculates instantly.

    Displayed value vs. stored value

    Formatting (Currency, Percentage, decimal places) only changes what you see. Excel always stores and calculates with the full, exact value.

    Classic trap: two cells holding 2.6 display as 3 each, but their sum is 5.2, which displays as 5. The sheet looks like it says 3 + 3 = 5.

    Order of operations

    Excel works through a formula in this order. Parentheses override everything, and operators on the same level go left to right.

    OrderOperatorExampleResult
    1Negation -=-3^29, since (−3)² comes first
    2Percent %=50%*84
    3Exponent ^=20/2^25
    4Multiply and divide * /=18/3*212, left to right
    5Add and subtract + -=3+4*211
    6Join text &="Q"&1+2Q3
    7Comparisons = < > <= >= <>=9-3*2>=2+1TRUE

    Comparisons always go last, so Excel finishes the math on both sides first and then returns TRUE or FALSE. In =6*2=3*4, the first = starts the formula and the second one compares: 12 = 12, so TRUE.

    Ranges and sheet references

    A range is the full rectangle between two corner cells, written with a colon. A4:B5 means A4, A5, B4, and B5. To count the cells in a range, multiply columns by rows: D3:F6 has 3 × 4 = 12 cells.

    To point at another sheet, write the sheet name, an exclamation point, then the cell: Payroll!F12. If the sheet name has a space, wrap it in single quotes: 'Q3 Sales'!B7. In any address the column letter comes first: K22 is column K, row 22.
